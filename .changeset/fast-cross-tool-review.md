New `vegafactory review <n>`: the cross-tool review in one command. It builds the packet (the brief's acceptance criteria, the plan's tasks, the diff stat, the changed files and `git diff -U5` against the base), starts the *other* tool read-only in the issue's worktree with that packet on stdin — `codex exec -s read-only --output-schema …` or `claude -p --tools Read,Grep,Glob --output-format json --json-schema …`, on the subscription with parent-app variables dropped — validates the JSON verdict and findings it returns, and posts the one review comment itself, so the reviewer never writes to GitHub. A fix round resumes the same reviewer session on the machine that ran it and sends only the fix diff and the open finding ids; on another machine a fresh reviewer gets the previous findings from the comment. At most three rounds, then a hand-back. Big (over ~800 lines or ~15 files) or `risky` diffs split into two parallel reviewers whose findings merge. A stuck reviewer is killed after 60 minutes and retried once; a failed review is always a hand-back, never a skipped review. Flags: `--base`, `--reviewer`, `--resume`, `--json`, `--dry-run`. Exit 0 clean, 2 needs-fixes or hand-back, 1 error. dev-review is rewritten around it, with the same-tool fresh-subagent review kept only as the labelled fallback when the other tool is missing; the `review:` knob is retired from the profile template.
