One command now runs every harness hook: `vegafactory hook <event> --harness claude|codex` for SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, SubagentStop, Stop and SessionEnd. It tells the session which issue it is on and who holds it, keeps the claim's heartbeat alive, commits and pushes a `wip:` checkpoint each turn, and stops file and shell tools in a worktree whose claim was taken back (saving its uncommitted work to a `rescue/` branch first). The ship guard now lives in the CLI: a fixed always-ask list plus the `ask:` commands in the `## Ship` section of dev.md on the default branch, and it lets `gh pr merge` through when the issue has a recorded "ship it". `vegafactory ship check <n>` replaces `ship-gate.mjs`. The operator now gives two words per issue — an ack and "ship it" — and the `gates:` knob is retired. Removed: `vegafactory guard sync`, the `.vegastack/hooks/` files, `ship-gate.mjs`, `reclaim.mjs` (use `vegafactory issue claim --take-back-by`) and `approval.mjs`; re-wire existing hook config to `vegafactory hook`. The repo's fast checks moved to a `commit-msg` hook that skips `wip:` commits.
