New: usage numbers and a local dashboard. `vegafactory stats collect` reads the new lines of the Claude Code and Codex session logs on this machine and keeps one record per assistant turn — time, your `gh` login, machine, repository, issue, harness, exact model id, skill, tokens, duration and outcome, and never a prompt, a file, tool arguments or which subscription paid; a skill is named only when it resolves to one installed on this machine or shipped in the bundle. Each log is read from a saved byte offset behind one lock and committed through a journal, so a session that was killed, a crash mid-write and two hooks at once all count each turn exactly once; a log replaced at the same path is re-read from the start, and a turn finished after the offset moved is corrected rather than lost. `stats push` appends those records to the org control room at `stats/YYYY/MM/DD/<operator>-<machine>.jsonl` — the operator and machine each turn was recorded on — with your own `gh` login, at most once an hour, only turns from repositories that room is bound to and behind that room's own cursor, and only into a clone that is exactly as `sync` left it: expected origin and branch, clean index and worktree, no unrelated local commits, only the generated files staged, and a rejected push retried by the next run; `stats show` prints turns, tokens and time by operator, project, model, stage and skill. `vegafactory dashboard` writes one self-contained HTML page — operators, projects, issues with their state and links, model use per operator and project, day bars and time per stage — with no server and no network. The harness hooks collect in the background at each turn boundary and ask to share at session start.
