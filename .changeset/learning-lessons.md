Sessions now leave lessons behind. At the end of a session that committed something, the Stop hook asks once — through each harness's own documented Stop continuation — for the general lessons it taught, the ones that would have saved time on any issue in the repository. The session records each with `vegafactory learning add`, and a session with nothing to add runs nothing. A chat-only session is never asked, and two sessions sharing a worktree keep their own starting point and their own answered state, so neither is asked for the other's commits. The queue is `.vegastack/.tmp/learnings.md`, git-ignored so it never leaves the machine; every read and write of it takes one lock and refuses a queue reached through a symbolic link. The next SessionStart lists what is waiting and tells the agent to propose each as one `.vegastack/dev.md` line, folded into an existing line where it fits, which lands only on the operator's explicit yes. `vegafactory learning add|list|accept|decline` never edits dev.md itself, and it covers the repository's own dev.md only — org and group control-room lines stay manual. Project setup now puts `.vegastack/.tmp/` in `.gitignore` alongside `.vegastack/.worktrees/`; a project set up before this should add that line.
