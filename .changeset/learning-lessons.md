Sessions now leave lessons behind. At the end of a session that did work, the Stop hook asks once — through each harness's own documented Stop continuation — for the general lessons it taught, the ones that would have saved time on any issue in the repository. A session counts as working on one of two kinds of evidence: its own turn checkpoint made the commit, or a commit landed during one of its own shell tool calls with no other session's shell tool running that could have made it instead. Each commit is ruled on once, by name. A session that only talked, only read, or only edited files is never asked on that account, and two sessions sharing a worktree are never asked for each other's commits. Each request names a scratch file in a folder made for that one request, refused if the name is taken or is a link; the session writes its lessons there and records them with `vegafactory learning add`, which reads that file or standard input, one lesson per line, and then removes the folder. Lesson text never travels on a command line, so a backtick or a dollar sign in a lesson stays text. A session with nothing to add runs nothing. The queue is `.vegastack/.tmp/learnings.md`, git-ignored so it never leaves the machine; every read and write checks each path component before taking its lock, refuses anything reached through a symbolic link, and replaces the file through a random, exclusively created temporary name — as the claim file, the session marks and the issue cache now do too. The next SessionStart lists what is waiting and tells the agent to propose each as one `.vegastack/dev.md` line, folded into an existing line where it fits, which lands only on the operator's explicit yes. `vegafactory learning add|list|accept|decline` never edits dev.md itself, and it covers the repository's own dev.md only — org and group control-room lines stay manual. Project setup now puts `.vegastack/.tmp/` in `.gitignore` alongside `.vegastack/.worktrees/`; a project set up before this should add that line.
